# TRABAJO FINAL - DATA SCIENCE
Repositorio del trabajo final de Data Science.

# REPRODUCCIÓN
El repositorio cuenta con 2 carpetas. Para la presentación en RMarkdown solo es necesario descargar la carpeta "Presentación-RMarkdown" y abrir el archivo "Presentación EDIS" con acceso a la carpeta que contenga las imágenes en formato PNG. Para ejecutar el código donde se realizó el tratamiento de las bases de datos, tablas, gráficos y regresiones se debe descargar la carpeta "Códigos y Bases de Datos". Una vez descargado solo hay que ejecutar el código con acceso a la carpeta que contenga la base de datos correspondiente. También se puede subir directamente la base de datos a R y ejecutar el código. Cabe destacar que son dos códigos prácticamente idénticos (solo varía el nombre de las variables según la base de datos), por lo que conviene limpiar el entorno y el epacio de trabajo cada vez que vayamos a ejecutar un código.
